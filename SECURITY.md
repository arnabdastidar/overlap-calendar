# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on this repository and include reproduction steps, affected versions, and likely impact.

## Sensitive data

Overlap is designed to avoid calendar content. A security report is especially important if you find that the app can expose group passwords, creator recovery keys, provider refresh tokens, event titles, event descriptions, guest lists, email, or contacts.

## Supported versions

Until the first stable release, security updates target the latest commit on the default branch.
